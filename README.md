# 📸 Polaroid Strip Generator

A fun and interactive web application that lets users capture photos using their webcam, apply aesthetic filters, and generate a Polaroid-style photo strip. Built for beginners, this project focuses on simple image processing, creative UI, and a smooth user experience.

⭐ Features

✔️ Capture images directly from the webcam

✔️ Apply multiple filters (B&W, vintage, warm tone, cool tone, etc.)

✔️ Automatically generate a Polaroid-style frame

✔️ Option to create a strip of 3–4 Polaroids

✔️ Save the final Polaroid strip as an image file

✔️ Beginner-friendly code structure

# 🛠️ Tech Stack

HTML5 – UI layout

CSS3 – Styling + Polaroid design

JavaScript – Camera handling, filters, image processing

Canvas API – Drawing Polaroid frames and exporting image

# 🚀 How It Works

Open the app

Click Start Camera

Capture your photo

Choose a filter

The app applies the filter and wraps the picture in a Polaroid frame

Optionally add more photos to build a Polaroid strip

Click Download to save
